# .NET-Obfuscator

A .NET Obfuscator is a software which is used to safeguard .NET applications against reverse engineering.

This is achieved by converting the original .NET MSIL source code into a form that is intentionally complex. This makes it significantly challenging for attackers to decompile and interpret the code.

A .NET Obfuscator serves to protect intellectual property rights and and mitigate potential security vulnerabilities.

.NET obfuscation has a few advantages such as reducing application size, which can improve performance and efficiency.

However, .NET Obfuscation is not bullet-proof and cannot guarantee complete protection against reverse engineering or malicious tampering, as determined attackers may still find ways to analyze and deobfuscate the code with sufficient time, effort and expertise.

This is an updated list based on [this](https://github.com/NotPrab/.NET-Obfuscator). It includes open source, trial and paid services to obfuscate .NET code.
Any suggestions or additions, feel free to open an issue.

### Open Source

* [ConfuserEx](https://github.com/yck1509/ConfuserEx) - An open-source, free protector for .NET applications.
* [Hex Virtualization](https://github.com/hexck/Hex-Virtualization) - Hex-Virtualization was built so that people can learn from it.
* [KoiVM](https://github.com/yck1509/KoiVM) - Virtualizing code protector and obfuscation plugin for .NET applications used with ConfuserEx.
* [LoGic.NET](https://github.com/AnErrupTion/LoGiC.NET) - A more advanced free and open .NET obfuscator using dnlib.
* [MemeVM](https://github.com/TobitoFatitoNulled/MemeVM) - A small virtualizer for .NET which works together with ConfuserEx.
* [MindLated](https://github.com/Sato-Isolated/MindLated) -  .net obfuscator using dnlib.
